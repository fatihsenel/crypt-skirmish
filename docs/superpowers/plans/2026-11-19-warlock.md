# Warlock Implementation Plan

> Executed natively in one session (the user asked to build straight after approving the design).

**Goal:** Add the Fiend Warlock as an optional class for Ilsa's slot.
**Architecture:** Same pattern as the Ranger: template `K` + `PROGRESSION.K` in `units.js`,
`CLASS_CHOICES.W = ['W', 'K']`, rules in `combat.js`, pact refill in `campaign.js`, then
visuals/HUD/title/sim.
**Spec:** docs/superpowers/specs/2026-11-19-warlock-design.md

## Global constraints
- `src/game/` stays free of three.js and DOM; all new dice go through `this.rng`.
- Old saves and replays keep working: Ilsa without `cls` stays a Wizard.
- SRD 5.1 names only.

## Review focus
- Hex on a foe that dies: the mark clears; a new Hex costs a slot.
- Hellish Rebuke armed but the warlock drops to 0 from the hit: no rebuke.
- Level 5 slot change (2nd → 3rd) with spent slots: slots never go negative.
- Temp HP: absorbs damage before HP, not carried to the next fight, not healed by potions.
- Scorching Ray when the target falls mid-volley: remaining rays go to the nearest other foe in range and sight, or are lost.

## Tasks
1. **Rules** (`units.js`, `abilities.js`, `combat.js`, `campaign.js`): template K, spells
   `eldritch blast` attack, `hex`, `scorchingRay`, rebuke toggle (`toggleRebuke`, `rebukeProblem`,
   replay command `rebuke`), `darkOnesBlessing` temp HP in `applyDamage`, `ownLuck` in `save`,
   `extraAttackWith`, pact refill in `completeFight`. Tests in `tests/rules.test.js`.
2. **Presentation** (`main.js`, `hud.js`, `unitView.js`, `effects.js`, `icons.js`,
   `modelSpecs.js`, `camp.js`, `daily.js`, `achievements.js`): animations, log lines, toggle
   button, temp HP on the HP bar, title switch, `&warlock`, icon, recolour.
3. **Simulator** (`scripts/sim.js`): `WARLOCK=1` policy; compare win rates with the Wizard.
4. **Docs:** README party table and house rules, CLAUDE.md unchanged.
5. **Browser check:** `?level=2&warlock`, desktop and 375×812.
